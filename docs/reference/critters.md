# Critters

Every critter this app knows, and every figure it uses for them. Rates are **per cycle**, which is how the game quotes a critter and how anybody checking one thinks.

Generated from the shipped data by `dart run tool/gen_reference.dart`, so it cannot disagree with what the app uses. If a number here is wrong, the app is wrong: say so at https://github.com/hbock-42/harmONIc/issues and quote the row.

A row marked **unverified** is one where something is a judgement rather than a published figure; the recipe says which part.

## What they give, one thing at a time

Read down a column, not across the page. Two critters giving the same thing should be within reach of each other, and the one that is not is the one to check.
